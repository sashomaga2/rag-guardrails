1. LangGraph request pipeline

Input classification and retrieval run in parallel, so the LLM guard adds no latency. Every exit path ends with a refusal, a verified answer or a human handoff.

2. Hybrid retrieval: recall, then precision

Dense vectors match meaning; BM25 matches exact tokens (error strings, SKUs). RRF merges them by rank, then a cross-encoder rescores the top 20. Access control is applied inside both queries.

    direction TB
    D["Chroma

    L["Elasticsearch BM25
minimum_should_match 2<60%

  end
  Q --> D
  Q --> L
  D -- "ranked list A" --> RRF["Reciprocal Rank Fusion
Σ w / (60 + rank)"]:::gate
  L -- "ranked list B" --> RRF
  RRF --> T20["top 20 candidates"]:::llm

    DROP["drop score < 0.05"]:::bad
    CAP["max 2 chunks per file"]:::warn

    CE --> DROP --> CAP --> TOP
  end
  T20 --> CE
  TOP --> CTX(["context for LLM"]):::start
  L -. "ES down → dense only" .-> RRF

4. Guarded streaming (SSE /chat/stream)

Text streams optimistically. Redaction holds back a small buffer, moderation runs in the background, and verification happens at the end. Anything already shown can be retracted.

sequenceDiagram
  autonumber
  participant C as Client UI
  participant API as FastAPI /chat/stream
  participant G as LangGraph
  participant R as Redactor ⑤
  participant M as Moderator ⑥
  participant V as check_output ⑦

  C->>API: POST question (message_id)
  API->>G: run graph
  API-->>C: status {stage: retrieving}
  loop each token
    G->>R: token
    R->>R: buffer, release len - holdback (never splits a match)
    R-->>C: delta {text}
    R-)M: every 240 chars (max 1 check in flight)
  end
  alt moderation flags text
    M-->>C: retract {reason, replacement}
    API->>G: close run (stop paying for tokens)
  else stream finished
    G->>V: full answer
    alt citations + grounding OK
      V-->>C: verified {citations, grounding_score}
    else failed once
      V-->>C: retract + regenerated answer (1 retry)
    else failed twice
      V-->>C: retract + handoff {ticket_id}
    end
  end
  API-->>C: done {run summary}

5. Live-agent handoff across pods (WebSocket + Redis Streams)

The desk webhook can land on any pod. Each conversation has a Redis Stream, and one shared reader per pod fans entries out to local sockets. Reconnecting clients resume from their last event ID.
